## 🎮 About the Project

**Threads** is a third-person game featuring a robot exploring a ruined world. The project focuses on gameplay programming, interactive systems, and the connection between player actions and the game world.

My work focuses on implementing gameplay mechanics in Unity and C#, including raycast-based targeting, cable connections, ability switching, and shader parameter controls.

This project is being prepared for a game contest. The full game project is not publicly available, but this repository contains selected code demonstrating my gameplay programming work.

---

## ⚙️ Technical Highlights

- **Engine:** Unity
- **Programming Language:** C#
- Third-person player movement
- Raycast-based aiming and interaction
- Interactive cable connection system
- Ability switching system
- Shader parameter controls
- Integration of gameplay logic with animations

## 🕹️ Core Gameplay Systems

### 🎯 Aiming and Interaction

Raycast-based targeting allows the player to aim at interactable objects and cable connection points.

The system provides a foundation for connecting player input with interactions in the game world.

**Technical focus:**
- Raycast-based target detection
- Interaction with designated objects and connection points
- Connecting aiming logic with gameplay interactions

---

### 🔌 Cable Connection System

The cable mechanic allows the player to connect cable endpoints to activate or power something in the game world.

This system makes connections between objects part of the gameplay rather than treating them as purely visual elements.

**Technical focus:**
- Cable endpoint interaction
- Connection-based gameplay logic
- Linking player interactions with world responses

---

### 🔄 Ability Switching

The player can switch between different abilities.

**Technical focus:**
- Ability selection and switching
- Connecting player input to ability behavior
- Integrating ability logic into the gameplay system

---

### 🎨 Shader Parameter Controls

Shader parameters can be controlled through gameplay code, providing a way to adjust visual effects through programmed interactions.

This work explores the relationship between gameplay systems and real-time visual feedback.

**Technical focus:**
- Controlling shader parameters through C#
- Connecting code-driven changes to visual effects

---

### 🤖 Third-Person Movement and Animation Integration

The game uses third-person movement as the foundation for player navigation and interaction.

Gameplay logic is integrated with animations so that character behavior and player actions work together.

**Technical focus:**
- Third-person movement
- Integration of gameplay logic with animations
- Coordinating player actions with character behavior

---

## 🧠 Gameplay Programming Focus

Threads emphasizes the implementation of interactive gameplay systems, including:

- **Player interaction:** Detecting targets and responding to player input.
- **World interaction:** Connecting cable endpoints to trigger gameplay effects.
- **Ability systems:** Switching between different player abilities.
- **Gameplay and visuals:** Controlling shader parameters through code.
- **Character control:** Combining third-person movement with animation behavior.

These systems reflect my interest in gameplay programming, interactive mechanics, and building clear connections between player input and in-game behavior.
